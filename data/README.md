# Data Sources

Synthetic source-style data for adtech audience discovery and consumer insights packaging.

- `entities.csv`: 36 audience opportunity records.
- `daily_metrics.csv`: 5,040 audience opportunity-day metric rows.
- `source_events.csv`: 760 operational events, QA checks, experiments, and stakeholder asks.
- `recommended_actions.csv`: 220 candidate actions with effort and expected lift.
